# Minesweeper

tiny js minesweeper  
No build tools required – just open `index.html` in your browser!

## Features

- Three difficulty levels (Easy / Medium / Hard)
- Flagging cells with right‑click
- Automatic flood‑fill for empty spaces
- Win/loss detection
- Responsive grid sizing

## How to run locally

```bash
git clone https://github.com/yourname/my-minesweeper.git
cd my-minesweeper
open index.html          # or double‑click it in Finder / File Explorer
